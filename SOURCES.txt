Pulsekit desktop and Android source
===================================

shared/src/pulsekit
  Compiled into BOTH public/Pulsekit.jar and the APK.
  Engine.java StyleDb.java AudioIo.java Mp3Decode.java
  JavaRun.java PromptRun.java PyJavRecent.java PyJavHints.java
  midiutil.py

desktop/src/pulsekit
  Desktop only (Swing UI, recent PyJav list, and AI prompt handoff).
  Pulsekit.java  — Main-Class pulsekit.Pulsekit
  PythonRun.java DesktopAi.java
  drum_midi.py
  MANIFEST.MF is desktop/MANIFEST.MF
  JavaScript and TypeScript run with Node.js on this computer.

android/src/pulsekit
  Phone-only. MainActivity.java is a decompiled activity; the APK build
  keeps a prebuilt MainActivity class and injects behavior with the
  patches under android/patch (Javassist). Other files compile normally,
  including ArtJava (ECJ+dx), ArtPy, ArtNode (Node.js through Termux),
  SogniClientClick, the Prompts screen, and PyJav.

android/AndroidManifest.xml
  package pulsekit.app, minSdk 24, targetSdk 33.
  Declares com.termux.permission.RUN_COMMAND so PyJav can run Node in Termux.

Not included: compiled class files, the APK, the JAR, android/pulsekit.jks.
